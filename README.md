## 📌 Project Overview

This project focuses on practical **Security Operations Center (SOC) threat detection, security monitoring, incident investigation, and incident response** in an authorized lab environment.

The project demonstrates how security analysts can monitor endpoint activity, analyze security alerts, investigate suspicious events, identify potential indicators of compromise (IOCs), and document incidents using a structured investigation workflow.

## 🎯 Objectives

- Understand SOC monitoring and threat detection workflows.
- Use Wazuh SIEM to monitor security events and analyze alerts.
- Explore Snort IDS for network intrusion detection.
- Investigate suspicious activities and correlate relevant security events.
- Identify and document potential Indicators of Compromise (IOCs).
- Develop incident classification, response, and reporting skills.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|

| Snort IDS | Network traffic monitoring and intrusion detection |
| Windows/Linux Lab | Endpoint monitoring and security testing |
| GitHub | Project documentation and evidence management |

## 🔍 Investigation Workflow

1. **Environment Setup** – Prepare the authorized SOC lab environment.
2. **Security Monitoring** – Monitor endpoint and network security events.
3. **Alert Detection** – Review alerts generated by the monitoring tools.
4. **Incident Investigation** – Analyze event details, timestamps, and related activities.
5. **IOC Analysis** – Document relevant indicators and suspicious artifacts.
6. **Incident Classification** – Assess the incident based on available evidence.
7. **Incident Response** – Recommend or perform appropriate containment and remediation actions in the lab.
8. **Final Reporting** – Document findings, evidence, impact, and recommendations.
